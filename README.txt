A+MENTOR APP PREVIEW

This is a responsive browser prototype to review the app look and flow on phone, tablet, laptop and desktop. It includes the tricolour logo and theme, sample study PDFs, MCQ interaction, a demo test with scoring, login screen mockup, and course/payment preview.

IMPORTANT LIMITATIONS
- This package is NOT an APK and is not ready for Google Play.
- Login is only a local UI demonstration; no account is created.
- Test scores are not stored or synced.
- Payment buttons are demo-only; no payment is collected.
- MCQ examples are sample practice content and are not labelled verified previous-year questions.
- PWA installation requires hosting over HTTPS; service-worker caching will not work when opening index.html directly as a local file.

HOW TO PREVIEW
1. Extract the ZIP on your computer.
2. Open index.html in a modern browser to review most UI features.
3. For PWA install/offline testing, host this folder on a separate test site over HTTPS. Do not overwrite the current live website.

NEXT BUILD STAGE
Wrap this prototype in an Android project and connect secure authentication, database, content management and a compliant payment provider. A signed APK must be built and tested before distribution.
